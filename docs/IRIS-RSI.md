# Bounded Forge RSI

Forge varies only allowlisted experiment parameters and evaluates challengers against a
sealed synthetic corpus. It records parent, hypothesis, configuration, cost, metrics and
promotion reason. It cannot mutate privacy, licensing, capability authority, benchmark
definitions, promotion rules or resource ceilings.

The running local autopilot performs bounded CPU experiments. Code-branch experiments,
real-data mixture search and external promotion are **BLOCKED** until isolated worker and
review workflows are configured.
