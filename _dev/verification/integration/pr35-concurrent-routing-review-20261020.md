# PR35: concurrent routing change blocks merge

Reviewed remote head `93f2b3416110931de5677d8b8fe2c1aaec47265e` on 2026-10-20. Origin verified as PentaVM/ArchieOS-Nvidia. Both GitHub checks (`rust`, `native-contracts`) succeed. This head adds voice/arena routing beyond the previously validated combined IRIS/design head `9a9815c`.

## Findings

1. **P1: Arena bypasses privacy on images and fallback.** In `core/crates/archie-arena/src/model.rs`, `Nebius::ask` enters `ask_private` only when `images.is_empty()` and a registry loaded. Images, a missing/invalid registry, and `NoModel`/other routing errors with a provider key all reach the direct HTTP request with original `system`, `text`, and image data. That request does not enforce `self.grade`. A restricted/secret request with images can therefore reach the cloud; a restricted text request with no registry also bypasses withholding. A local inference failure can fall through to cloud without veiling. Keep every route behind the same privacy decision and fail closed when policy/registry resolution fails. Cover image, absent registry, and local failure cases with a loopback transport that records zero outbound requests when withheld.

2. **P1: Tool arguments bypass the outgoing veil.** In `core/crates/archie-model-runtime/src/routed.rs`, `disclose_chat` covers message content but clones assistant `tool_calls` unchanged. It also clones request tool definitions unchanged. `stream.rs` serializes `ToolCall.arguments` into the provider request. A secret occurring only in a historical tool argument is absent from both cover/residue checks yet leaves with the cloud request. Cover all free text/JSON string values that leave, or withhold unsupported structured payloads; keep tool protocol identifiers consistent. Test an assistant call containing a credential with no assistant content and inspect the complete serialized outgoing request.

3. **P2: Non-public cloud-only chat fails before veiling.** `disclose_chat` returns `NoModel` when the original privacy grade has no callable model, before attempting the public veiled request. The existing `disclosure` method deliberately tolerates no original candidate so it can veil Internal/Sensitive text. With shipped public-only cloud manifests and no local model, these chat grades never reach the intended veil path. Add cloud-only Internal/Sensitive coverage as well as the existing local/Secret test. Restricted and Secret must still be withheld when no eligible local model exists.

These are source-path findings, not evidence of an actual disclosure or a measured production incident. No provider request, GPU workload, model inference, training data admission, process change, or active Claude file modification was performed. Existing green CI does not cover the above cases. PR35 remains open; PR41 is merged. Sentry/Wanda stacks remain excluded. The previously uploaded WSL is still the frozen `61ad39f` artifact and does not include a later IRIS Rust merge.
